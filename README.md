# Inhaosin - Professional Digital Printing Ink Solution

This repository contains the source code for the official website of **Inhaosin**, a leading manufacturer of high-quality digital printing inks and consumables.

## Website Features
- **Modern Design**: Professional White/Blue theme with a factory-strength aesthetic.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Product Catalog**: Detailed categories for DTF, UV, Eco-Solvent, and Sublimation inks.
- **Conversion Focused**: Integrated inquiry forms and CTA buttons.
- **Contact System**: Powered by Web3Forms for direct email inquiries.

## Deployment Information
- **Hosting**: Cloudflare Pages (Free Tier)
- **Domain**: [inhaosin.com](https://www.inhaosin.com)
- **Framework**: Tailwind CSS (via CDN)

## How to Update
1. Edit `index.html` to update text or images.
2. Ensure the `access_key` in the contact form is updated with your Web3Forms key.
3. Push changes to Github; Cloudflare Pages will automatically redeploy.
